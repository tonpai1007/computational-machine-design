# MDIE Project Deliverables Directory

This directory stores engineering deliverables and generated project artifacts produced by MDIE runs:

- **`.step`**: ISO 10303 CAD solid assembly models
- **`.stl`**: Watertight 3D print slicing meshes
- **`.scad`**: Parametric OpenSCAD CSG source models
- **`.html` / `.docx`**: Interactive engineering audit and academic calculation reports
- **`drawings/`**: Vector blueprints and dimensioned part sheets (`.svg` / `.pdf`)

By default, subdirectories within `Project/` (such as `Project/chair/`, `Project/shaft/`) are ignored by Git to keep the repository clean of large binary artifacts.
